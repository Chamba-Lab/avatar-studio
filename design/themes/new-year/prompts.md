# New Year: assets

Season: 26 Dec to 10 Jan (Christmas runs 1 to 25 Dec, so the two hand over on Boxing Day).
Palette: gold `#F9A825`, light gold `#FFD54F`, deep gold `#C77C02`, champagne `#FBE3A1`, cream
`#FCF6E8`, midnight `#24305E` / `#34437E`, sky `#90CAF9`, red `#E53935`, ink `#111111`.

No year numbers on any asset: the style guide bans text, and a "2027" sticker would expire.

Method: **SVG (Claude)** is drawn in code following `design/style-guide.md`; **Generate** needs an
image model, with the base prompt from the style guide plus the item prompt below.
